The problem

Placement season is a triage problem,
and nobody hands you the ruler.

  • 01A final-year student has a resume that overstates some things and understates others — and no way to know which.
  • 02Twenty things they could study; a fixed number of weeks. Which one actually changes whether they get an offer?
  • 03Career platforms answer with generic recommendations. AI chatbots answer with a different number every time you ask.
The thesis

The model extracts.
Code decides.

One model call reads the resume — not to score it, but to report evidence: what was built, what shipped, what has tests, with a page and line for every claim. Everything after that is arithmetic over a published, versioned benchmark.

How it works

One pipeline, one checkpoint.

ParsePDF → page/line-indexed text. OCR fallback for scans.
→
ExtractThe one model call: evidence signals + cited flags. No score field exists.
→
VerifyEvery quote checked against its cited page & line. Hallucinations dropped.
→
Score · Rank · ScheduleWeighted gap points; a 14-week plan from a topological sort.
→
DashboardsSkill map, roadmap, practice, progress — all reading the same rows.

The extraction is cached role-independently — so switching target roles re-measures everything instantly, with zero model calls.

The plan

14 weeks, three lanes, prerequisite-ordered — Docker lands in week 1 because the load test needs it — packed under the hours the student actually has.

The practice

Projects and interview drills ranked by weighted gap points; certifications re-scored live in the browser as a budget slider moves.

The proof

Readiness moves only when a gap closes — and a read-only link lets a recruiter see the scoreboard, never the resume.

Why trust it

Three things a judge can check
in the next five minutes.

  • 01The ruler is public. Open /benchmarks logged out: every required level, weight, formula and evidence weight — with a worked example computed at render time by the real scoring function.
  • 02Citations are real. Every flagged resume line quotes p.N L N — and the guard already dropped any quote that isn't literally there.
  • 03Role switch is instant. Same evidence, different bar, every number re-derived in one round trip. If a model were scoring, this would be impossible.
